# Northwind Business Insights using SQL

## Project Overview

This project contains a comprehensive collection of SQL queries developed using the Northwind database. The objective is to solve real-world business problems and generate actionable insights from sales, customers, products, employees, and shipping data.

The project demonstrates SQL skills ranging from basic querying to advanced analytical techniques.

---

## Dataset

Database Used: Northwind

The Northwind database is a sample business database containing information about:

- Customers
- Orders
- Products
- Categories
- Employees
- Suppliers
- Shippers
- Order Details

---

## Project Objectives

- Analyze sales performance
- Identify top customers and products
- Evaluate employee performance
- Monitor shipping efficiency
- Generate revenue insights
- Practice advanced SQL concepts
